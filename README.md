# sapling-samples

Examples of how you can use Sapling's JavaScript and Python libraries, including grammar checking and AI detection.

To run the samples, register for an account at [https://sapling.ai](https://sapling.ai/user/register)
and generate a development API key in your dashboard.

| Sample | Description |
|--------|-------------|
| [`html/`](html/) | Minimal HTML pages using the Sapling browser SDK, for grammar checking and AI detection |
| [`editors/`](editors/) | Sapling SDK integrated with rich-text editors: CKEditor, Froala, Lexical, Quill, TinyMCE and Tiptap |
| [`javascript/script/`](javascript/script/) | Node.js scripts using `@saplingai/sapling-js` for grammar checking and AI detection (ES module and CommonJS) |
| [`javascript/react-app/`](javascript/react-app/) | React app built with Vite, with a Check AI button |
| [`javascript/vue-app/`](javascript/vue-app/) | Vue 3 app built with Vite, with a Check AI button |
| [`javascript/angular-app/`](javascript/angular-app/) | Angular app with a Check AI button |
| [`javascript/express-app/`](javascript/express-app/) | Express backend that proxies Sapling API calls so the API key stays private, with a React frontend and a Check AI button |
| [`python/scripts/`](python/scripts/) | Python scripts using the `sapling-py` client, for grammar checking, AI detection and text analysis |
| [`dart/`](dart/) | Dart script that calls the HTTP API and applies edits to text |
