# Sapling HTML Example

- Replace `<YOUR_API_KEY>` with your Sapling API key.
- Open `editor.html` in a web browser for grammar checking, or `ai_detect.html` for AI detection. In `ai_detect.html`, click **Check AI** to see an overall score and highlights on the sentences flagged as AI-generated.
- WARNING: Do not serve these files publicly as it exposes the API key. Refer to this [documentation](https://sapling.ai/docs/sdk/HTML/quickstart#deploying-to-production) for how to deploy to production.
